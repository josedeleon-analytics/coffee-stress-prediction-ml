\# Coffee \& Stress Prediction (Supervised ML) — ALY6040



This project analyzes how coffee consumption and lifestyle/health factors relate to \*\*stress level\*\* (Low / Medium / High) using a \*\*synthetic health dataset (n = 10,000)\*\*.



The workflow covers:

\- Exploratory Data Analysis (EDA)

\- Feature engineering

\- Leakage detection and control

\- Class imbalance handling (upsampling inside cross-validation folds)

\- Model comparison: Multinomial Logistic Regression, Random Forest, XGBoost



\## Key Results (Test Set)

\- \*\*Best model:\*\* XGBoost

\- \*\*Accuracy:\*\* 0.994

\- \*\*Macro-F1:\*\* 0.985

\- \*\*ROC-AUC (multiclass):\*\* 0.9997

\- Dominant predictors: \*\*Sleep\_Hours\*\*, \*\*Health\_Issues\_Num\*\*
